# README - Tema 2 SDA

Se cere implementarea unei retele de sateliti organizata sub forma unui arbore binar, construit pe baza unui `Min-Heap`. Satelitii o sa fie caracterizati de doua campuri: un nume (de tip `char*`, unic; se stie ca acesta poate avea maxim 15 caractere) si o frecventa (de tip `int`). In arborele binar construit, cu cat frecventa este mai mare cu atat acesta este mai aproape de radacina (nodul cu cea mai are frecventa este radacina). 
Pentru construirea arborelui o sa se foloseasca un `min-heap`, care stocheaza nodurile arborilor. Acesta este ordonat dupa frecventa si apoi dupa nume (in mod alfabetic, atunci cand frecventa celor doi sateliti este egala).
Programul va primi, ca argumente in linia de comanda, cerinta pe care programul doreste sa o rezolve, dar si numele fisierelor de intrare/iesire.
Se verifica daca s-au primit parametrii necesari rezolvarii, si apoi daca fisierele s-au deschis cu succes. In caz contrar, o sa se afiseaza un mesaj de eroare. 
Indiferent de cerinta ceruta, initial o sa se formeze heap-ul, iar mai apoi arborele. Se citeste primul rand care contine numarul de sateliti `n` si se aloca un heap gol cu `n` pozitii. Apoi, pentru fiecare satelit, se citeste o linie din fisier (frecventa si numele satelitului), se aloca memorie pentru numele satelitului, se creeaza un nou nod si se insereaza acesta in min-heap.
Dupa popularea heap-ului, se construieste arborele cu functia `construiesteArb()`.
Mai apoi, se vede ce task doreste cerinta sa rezolve.

## **Task1**
`Task-ul 1` cere sa se afiseaza arborele creat.  
- functia `alocHeap()`: aloca memorie si initializeaza o structura de tip Min-Heap, care o sa aiba maxim nrMax elemente (initializeaza numarul curent de elemente nrElem la 0).
- functia `insertMinHeap()`: insereaza un nod in Min-Heap, pastrandu-i proprietatea de heap (info(parinte) < info(fiu_stanga), info(fiu_dreapta)). Functia adauga nodul la finalul vectorului v si il compara cu parintele sau. Se vor interschimba valorile celor doua noduri daca cel abia introdus are o frecventa mai mica (sau in caz de egalitate, daca are numele mai mic din punct de vedere lexicografic). Se va repeta procesul pana cand nodul ajunge pe pozitia corespunzatoare si se va creste numarul de elemente aflate curent in heap. In cazul in care heap-ul este plin, se va afisa un mesaj de eroare "nu mai e loc in heap".
- functia `comp()`: compara doua noduri conform cerintei. Aceasta a fost implementata pentru lizibilitatea codului, dar si pentru a nu scrie cod redundant.
- functia `extragereHeap()`: scoate si returneaza radacina (adica nodul cu cea mai mica radacina) heap-ului. Functia salveaza intr-o variabila radacina, pe care la final o s-o returneze, si o inlocuieste cu ultimul element din vector. Apoi, coboara elementul nou de la radacina pentru a pastra proprietatea de min_heap (interschimba valorile celor doua noduri pana cand acesta va ajunge pe pozitia corecta). De asemenea, daca heap-ul este gol si se incearca extragerea, se va afisa un mesaj de eroare (`heap ul este gol`).
- functia `construiesteArbore()`: rezolva cerinta; acesta costruieste arborele binar cerut, combinand nodurile din heap. Functia repeta extragerea a doua noduri cu frecvente minime si creeaza un nou nod, cu frecventa totala si cu numele concatenat. In plus, se atribuie nodurile extrase drept fii, stanga si dreapta, avand grija sa se respecte cerinta in legatura cu frecventa si cu ordinea alfabetica. La final, se insereaza noul nod in heap. Functia va returna radacina arborelui construit.
- functia `calcNivel()`: calculeaza inaltimea arborelui; este una dintre cele 3 functii necesare afisarii arborelui pe niveluri. Aceasta determina, recursiv, inaltimea subarborelui stang si drept. Returneaza 1 + inaltimea maxima dintre cele doua (+1 ca sa se ia in calcul si nivelul 0 - radacina).
- functia `afisareNivelArb()`: afiseaza nodurile de pe un nivel dat din arbore, in fisierul primit ca parametru. Se parcurge recursiv arborele si cand nivelul cerut ajunge sa aiba valoarea 0, se afiseaza nodul curent. In caz contrar, se scade nivelul si se continua coborarea in subarborii stang si drept.
- functia `afisareArb()`: afiseaza arborele pe nivele, nivel cu nivel. Initial, se calculeaza inaltimea arborelui, cu ajutorul functiei calcNivel. Apoi, pentru fiecare nivel, se apeleaza afisareNivelArb pentru a afisa nodurile de la nivelul respectiv, trecand apoi pe alta linie.

# **Task2**
`Task-ul 2` cere decodificarea unor siruri binare.
Pentru fiecare sir binar din fisier, se apeleaza functia `decode()`.
- functia `decode()`: parcurge arborele si afiseaza numele satelitului/satelitilor decodati. Se porneste de la radacina. Se parcurge fiecare caracter din sirul codif (de tip `char[]`, maxim 1000 de caractere): daca este 0, merge in subarborele stang, iar daca este 1, merge in subarborele drept. La fiecare pas, se verifica daca nodul este frunza. In caz afirmativ, se afiseaza numele satelitului in fisierul de iesire primit ca parametru si se revine la radacina arborelui pentru a continua decodificarea. La final, dupa ce tot sirul a fost decodificat, se scrieun newline in fisier.

# **Task3**
`Task-ul 3` cere codificarea unor nume de sateliti.
Pentru fiecare satelit din fisier, se cauta calea binara (codul - de la radacina la satelit; 0 inseamna fiu stang, 1, fiu drept).
- functia `code()`: cauta nodul frunza cu un anumit nume in arborele binar si construieste codul binar asociat traseului (de la radacina la frunza). Va scrie in fisierul primit ca parametru. Se verifica daca arborele este gol. In caz afirmativ, se va afisa un mesaj de eroare. Apoi, se verifica daca nodul curent este frunza, iar, daca da, pune terminator la sirul codif si il afiseaza in fisier. De asemenea, functia returneaza 1, semn ca a fost gasit satelitul cerut. Daca nu este frunza, se adauga caracterul '0' in vectorul codif[] si se face un apel recusiv in subarborele stang. Daca satelitul nu se situeaza in subarborele stang, se suprascrie pozitia curenta din codif[], unde scrisesem '0', cu '1' si se continua cautarea in subarborele drept. Daca satelitul nu se afla in niciun dintre arbori, functia intoarce 0, semn ca nu exista satelitul cerut in arborele nostru.

# **Task4**
`Task-ul 4` cere sa determinam cel mai apropiat satelit parinte comun pentru toate nodurile din fisier.
In `int main()`, se aloca memorie pentru un vectori de siruri de caractere nume, care va contine numele fiecarui satelit din fisier. Apoi, se apeleaza functia `findParent()` pentru a determina nodul parinte comun. La final, va fi eliberata memoria alocata pentru vectorul de siruri nume.
- functia `findPath()`: salveaza calea de la radacina arborelui pana la un anumit nod frunza intr-un vector de noduri. Se verifica daca am gasit nodul dorit cu ajutoul variabilei ok (daca da, iesim din functie). Daca nu, salvam adresa nodului curent in vectorul paths. Verificam daca nodul curent este cel cautat. Daca da, punem NULL pe urmatoarea pozitie din vector, pentru a marca finalul drumului, setam ok = 1, pentru a marca ca am gasit satelitul cautat si iesim din functie. Daca nodul curent nu este cel cautat, atunci continuam recursia in subarborele stang, crescand nivelul cu 1. Daca nu se gaseste nimic in stanga, mergem in subarborele drept.
- functia `findParent()` - determina cel mai apropiat satelit parinte comun. Prima data vom aloca memorie pectru vectorul de cate un vector de pointeri la noduri pentru fiecare satelit (paths[i] va contine calea de la radacina pana la satelitul cu nume[i]). Pentru fiecare satelit, salvam drumul, apoi calculam lungimea acestuia si o salvam in vectorul levels. Aflam care e cea mai scurta cale, deoarece nu are sens sa comparam mai adanc decat aceasta - nu poate exista un stramos comun acolo. Se va parcurge in paralel caile de la radacina catre fiecare satelit, pozite cu pozitie, si se va retine ultimul nod care apare in toate caile - acela este cel mai apropiat satelit parinte comun. La final, se va elibera memoria alocata pentru paths.

# **Eliberarea memoriei**
La finalul rezolvarii cerintei cerute, se elibereaza memoria Arborelui:
- functia `distrugereArb()`: elibereaza memoria arborelui, nod cu nod (nu este necesar sa eliberam separat nodurile din min-heap). Se elibereaza recursiv subarborii stang si drept (elibereaza sirul din nume al nodului si apoi nodul in sine).
